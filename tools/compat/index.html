Olemmy compatibility check

Runs the checks of scripts/compat.mjs from a real browser, so CORS is decided by the browser itself. Serve this folder from any origin (python3 -m http.server -d tools/compat 8000) and press Run. The upload check posts a 1×1 PNG with a made-up token: it can't upload anything, but shows whether the browser lets the request through.
